# ProQuote — تطبيق سطح المكتب (Electron)

نظام إدارة عروض الأسعار والمستندات — إصدار Electron v5.3.0

---

## ✅ المراحل المُنجَزة

### المرحلة 1 — تحويل إلى Electron + exe
- ملف HTML واحد → تطبيق Electron كامل بعمليتين (main + renderer).
- كل الموارد محلية (تعمل دون إنترنت تماماً): Tailwind, Font Awesome, 4 خطوط عربية, html2pdf, qrcode.
- أمان: `contextIsolation: true`, `nodeIntegration: false`, جسر `preload` محدود.
- أيقونة واسم البرنامج: `ProQuote` v5.3.0.

### المرحلة 2 — مثبت NSIS احترافي
- معالج تثبيت متعدد الخطوات (اختيار مجلد، اختصارات).
- صورة جانبية مخصصة (164×314) + رأس علوي (150×57) بألوان ProQuote.
- اتفاقية ترخيص عربية تُعرض أثناء التثبيت.
- اختصارات: سطح المكتب + قائمة ابدأ (تحت قسم ProQuote).
- إلغاء تثبيت آمن (لا يمس بيانات المستخدم في `%APPDATA%`).

### المرحلة 3 — تخزين دائم + ترحيل + نسخ احتياطي
- **طبقة تخزين JSON دائمة** (`proquote.data.json` في `%APPDATA%\ProQuote\`) بديل SQLite نقي (لا يتطلب Python/Build Tools).
- فصل بيانات المستخدم عن ملفات البرنامج — البيانات تنجو عند التحديث/إلغاء التثبيت.
- **ترحيل تلقائي**: عند أول تشغيل، يعرض التطبيق خيار استيراد نسخة احتياطية سابقة (`.json` أو `.pqbak`).
- **نسخ احتياطي تلقائي يومي** (آخر 7 نسخ في `userData/backups/`).
- **نسخ احتياطي يدوي + استعادة** عبر زرين في لوحة التحكم.
- يحافظ على **كل دوال localStorage الأصلية** (لا تعديل على منطق العمل).

### المرحلة 4 — نظام الترخيص
- **بصمة فريدة للجهاز** (8 أحرف) من معرّفات الأجهزة + SHA256.
- **نسخة تجريبية** (14 يوماً) مع مقاومة للتلاعب (ملف مرخّص HMAC في موقعين).
- **تفعيل بمفتاح مرتبط بالجهاز** (AES-256-GCM + Base64).
- **أداة مولّد المفاتيح** (`src/main/keygen.js`) لتوليد مفاتيح للعملاء.
- واجهة تفعيل في الشريط الجانبي + شارة حالة (تجريبية/مُفعّل/منتهي).

### المرحلة 5 — التحديث التلقائي (جاهز للتفعيل)
- بنية `electron-updater` كاملة (`src/main/updater.js`).
- تحقق يدوي + تنزيل + تثبيت + تراجع.
- **يتطلب خادم تحديثات** عند التوزيع التجاري (يُفعّل بتعديل سطر واحد في `main.js`).
- نسخة احتياطية تلقائية قبل كل تحديث.

### إضافة — استيراد/تصدير المنتجات
- استيراد من **CSV** بدعم الأعمدة العربية والإنجليزية.
- **كشف تلقائي للأعمدة**: الكود، الاسم، الوصف، السعر، الوحدة، الرابط، **رمز الجمركي (HS)**، **التكويد المصري (EGS)**.
- وضعان: دمج (تحديث بالكود) أو استبدال كامل.
- تصدير كل المنتجات إلى CSV (مع BOM للعربية).

## 🚀 التطوير

```bash
# المتطلبات: Node.js LTS (≥ 20)

npm install           # تثبيت الاعتماديات
npm run dev           # تشغيل في وضع التطوير (مع DevTools)
npm start             # تشغيل عادي
```

## 📦 البناء

```bash
npm run dist:win      # → dist/ProQuote-Setup-5.3.0.exe (مثبت NSIS)
npm run pack          # → dist/win-unpacked/ProQuote.exe (نسخة محمولة)
```

## 🔑 توليد مفتاح ترخيص للعميل

```bash
# صيغة الأمر:
node src/main/keygen.js <معرّف_الجهاز> [النسخة] [أيام_الصلاحية]

# مثال:
node src/main/keygen.js E17AF2B0 professional 365
node src/main/keygen.js A1B2C3D4 enterprise 0    # نسخة مؤسسات دائمة
```

**سير العمل**:
1. يُعطي العميل معرّف جهازه (من نافذة التفعيل في التطبيق).
2. تشغّل `keygen.js` بمعرّفه للحصول على مفتاح مرتبط بجهازه.
3. يُدخل العميل المفتاح → يُفعّل فوراً (دون إنترنت).

## ⚠️ ملاحظات التوزيع التجاري

1. **SmartScreen**: المثبت غير موقّع رقمياً. عند التوزيع التجاري، اشترِ شهادة **Code Signing (OV/EV)** وأضفها لـ `package.json`:
   ```json
   "win": { "certificateFile": "cert.pfx", "certificatePassword": "..." }
   ```
   أزل `"signAndEditExecutable": false`.

2. **خادم التحديثات**: لتفعيل التحديث التلقائي، ارفع المثبتات وملف `latest.yml` إلى خادم، ثم عدّل في `main.js`:
   ```js
   updater.init(mainWindow, { provider: 'generic', url: 'https://yourserver.com/proquote/updates/' });
   ```

3. **الترخيص**: نظام المفتاح العام (RSA-2048) — البرنامج يحمل المفتاح العام فقط؛ التوليد والتفعيل سيرفرياً عبر Supabase Edge Functions (docs/ONLINE-GUIDE.md).
