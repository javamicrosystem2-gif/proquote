# نشر ProQuote على Cloudflare Pages — دليل المطور

> **الفلسفة**: موقعك العام = **صفحة هبوط فقط** (الأسعار + التحميل + التواصل). البرنامج نفسه يُوزع عبر **GitHub Releases** بترخيصه ونظامه التجاري — ولا تُنشر نسخة ويب عامة إطلاقاً (بلا ترخيص = منتج مجاني يقتل الاشتراكات).
> **التكلفة**: مجاني للأبد، بلا بطاقة بنكية.

---

## ١) إنشاء الحساب والمشروع (مرة واحدة)

1. سجّل في **dash.cloudflare.com** (بريد فقط)
2. **Workers & Pages ← Create ← Pages ← Upload assets**
3. اسم المشروع (مثال): `proquote`
4. اسحب مجلد **`web-dist`** (يحتوي `index.html` الهبوط + `_headers`) ← **Deploy**
5. رابط موقعك: `https://<اسم-المشروع>.pages.dev` مع SSL تلقائي

> ملاحظة: رفع **المجلد** وليس zip القديم — حتى يُطبَّق ملف `_headers` (ترويسات الأمان).

## ٢) ربط دومين خاص (اختياري)

Workers & Pages ← المشروع ← **Custom domains** ← أضف دومينك ← SSL يصدر تلقائياً خلال دقائق.

## ٣) ⭐ تحديثات المطور بعد كل تعديل — القناتان

### أ) تحديث صفحة الهبوط (أسعار، روابط، إعلانات)
من اللوحة: **Workers & Pages ← المشروع ← Create new deployment ← اسحب مجلد `web-dist` المحدَّث ← Deploy** — يظهر فوراً على نفس الرابط.

أو من سطر الأوامر (أسرع للتحديثات المتكررة):
```bash
cd proquote-electron
set CLOUDFLARE_API_TOKEN=توكن_صفحات_من_لوحة_Cloudflare
set CLOUDFLARE_ACCOUNT_ID=معرف_حسابك_من_اللوحة
npx wrangler pages deploy web-dist --project-name=proquote --branch=main
```
> أنشئ التوكن من: My Profile ← API Tokens ← قالب **Cloudflare Pages — Edit** — واحذفه إن شئت بعد كل مرة.

### ب) تحديث البرنامج نفسه (يصل للمشتركين تلقائياً)
1. GitHub ← مستودعك ← **Releases ← Draft new release**
2. الوسم: `v9.6.1` (رقم النسخة الجديدة) — أرفق `dist\ProQuote-Setup-9.6.1.exe`
3. **Publish**
4. البرنامج عند المشتركين يفحص `releases/latest/download/` تلقائياً (حسب رابط التحديث في إعداداته) ويعرض التحديث — ثم يُحدّث زر «تحميل المثبّت» في صفحة الهبوط بنفس الرابط ويعاد نشر الهبوط (القناة أ).

## ٤) بعد الإطلاق — قائمة تشغيل الموقع

| الفحص | المتوقع |
|---|---|
| فتح الرابط | صفحة الهبوط: الباقات الشهرية/السنوية + مفتاح اللغة EN/عربي |
| أزرار الاشتراك | تفتح صفحات PayPal (صيغة subscribe?plan_id=) |
| تلجرام/فيسبوك/البريد | t.me/javamicro • facebook.com/proquoteamrnada • amrnada@mail.ru |
| زر تحميل المثبّت | يحمّل أحدث Release من GitHub |
| شارة التجربة | «🎁 تجربة مجانية 30 يوماً» ظاهرة |

## ٥) ملاحظات فنية

- `_headers` يضبط ترويسات الأمان تلقائياً (nosniff + Referrer-Policy)
- التحديثات لا تغيّر الرابط أبداً — كل نشر يستبدل الملفات فوراً
- التراجع عن أي نشر: **Deployments ← إصدار سابق ← Rollback**
- Blogspot (اختياري): نفس محتوى `landing/index.html` يمكن لصقه كصفحة موازية في مدونتك — المصدر واحد والمخرج مزدوج
- نسخة ويب عامة: **غير منشورة عمداً** — أي تسويق تجريبي مستقبلي عبر الويب يصمم كـ«عرض تجريبي محدود الميزات» لا كبرنامج كامل
