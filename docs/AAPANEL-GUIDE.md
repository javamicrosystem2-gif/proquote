# دليل استضافة ProQuote على aaPanel — خطوة بخطوة

> **الهدف**: تشغيل نسخة الويب من ProQuote على سيرفرك الخاص عبر aaPanel — بدل Vercel نهائياً.
> **المعمارية**: الموقع ملفات ثابتة فقط (مجلد `web-dist`) — لا يحتاج Node أو قاعدة بيانات؛ المزامنة تعمل من المتصفح إلى Supabase مباشرة.

---

## المتطلبات المسبقة

| المتطلب | ملاحظات |
|---|---|
| سيرفر Ubuntu 22.04 | الأفضل مجانياً: Oracle Cloud Free Tier (cloud.oracle.com — بطاقة للتحقق فقط) |
| وصول SSH للسيرفر | من Windows: `ssh root@IP_SSRVER` (Terminal/PowerShell) |
| مجلد `web-dist` من المشروع | أو ملف `web-dist.zip` الجاهز |

---

## ١) تثبيت aaPanel 8.0.6

اتصل بالسيرفر ثم نفّذ سطراً واحداً:

```bash
URL=https://www.aapanel.com/script/install_7.0_en.sh && bash <(curl -sL $URL) aapanel
```

- اكتب `y` للموافقة، وانتظر 2-5 دقائق.
- في النهاية ستطبع لك اللوحة: **العنوان** (مثل `http://IP:7800/xxxx`) و**اسم المستخدم وكلمة المرور** — انسخها واحفظها فوراً.

### تأمين أولي (دقيقتان — لا تتخطَّها)
1. افتح رابط اللوحة وسجّل الدخول.
2. **Panel Settings ← Panel User / Panel Password**: غيّرهما لقويين.
3. من مزوّد السيرفر (Oracle Security List / مجموعة الأمان): اسمح بالمنافذ **80 و443** فقط للعامة، ومنفذ اللوحة (7800) لعنوان IP الخاص بك إن أمكن.
4. فبّل تثبيت حزمة **LNMP** التي تقترحها اللوحة (Nginx فقط يكفي — MySQL وPHP غير مطلوبين، يمكنك إلغاؤهما لتوفير الذاكرة).

---

## ٢) إنشاء الموقع

من اللوحة: **Website ← Add Site**
- **Domain**: دومينك (من الخطوة 3) أو `IP_SRRVER` مؤقتاً للبدء بدون دومين.
- **PHP Version**: `Pure Static` (ملفات ثابتة فقط).
- اضغط **OK** — سيُنشأ مجلد الموقع في: `/www/wwwroot/<اسم-الموقع>/`

---

## ٣) دومين مجاني (DuckDNS) — اختياري لكن موصى به

بدون دومين يعمل الموقع على `http://IP` فقط (بلا HTTPS). للدومين المجاني:

1. سجّل دخولاً بـ GitHub على **duckdns.org**
2. أنشئ دوميناً فرعياً: مثل `proquote` ← يصبح `proquote.duckdns.org`
3. ضع فيه عنوان IP سيرفرك ← Update
4. أعد فتح إعدادات الموقع في aaPanel ← **Domains** ← أضف `proquote.duckdns.org`

---

## ٤) رفع ملفات الموقع

### الطريقة أ (الأسهل — من متصفح اللوحة)
1. من جهازك: انسخ مجلد `web-dist` واضغطه ZIP (أو استخدم `web-dist.zip` الجاهز من المشروع).
2. في اللوحة: **Files ← /www/wwwroot/<اسم-الموقع>/**
3. احذف ملف `index.html` الافتراضي و`404.html` إن وُجدا.
4. **Upload ← اختر الـZIP ← رفعه ← زر Extract (فك الضغط)** ← انقل محتويات المجلد الناتج إلى جذر الموقع.

### الطريقة ب (سطر أوامر من Windows)
حرّر أعلى ملف `upload-site.cmd` المرفق (SERVER وSITE_DIR) ثم شغّله — سيرفع المحتويات بـ scp.

---

## ٥) شهادة SSL (تتطلب دوميناً)

من **Website ← إعدادات موقعك ← SSL ← Let's Encrypt**:
- اختر الدومين ← **Apply** ← انتظر دقيقة ← فعّل **Force HTTPS**.

---

## ٦) اختبار التشغيل — قائمة فحص

افتح `https://proquote.duckdns.org` وتأكد:

| الفحص | المتوقع |
|---|---|
| الصفحة الرئيسية تفتح | شاشة الدخول/لوحة التحكم تظهر بلا أخطاء كونسول (F12) |
| تبديل اللغة EN/عربي | يعمل (قاموس v3 محمّل من `i18n/`) |
| الإعدادات ← المزامنة السحابية | لصق بيانات Supabase ← «اختبار الاتصال» = ناجح ✓ |
| إنشاء مستخدم + دخول | يعمل (يُحفظ في متصفح المستخدم) |
| زر تيليجرام في المعاينة | يفتح تيليجرام (يعمل من المتصفح عبر t.me مباشرة) |

> **ملاحظات نسخة الويب**: الترخيص والأجهزة المرتبطة بها لنسخة الكمبيوتر فقط (البرنامج يعرض تنبيهاً ودياً). الطباعة تعمل من المتصفح. البيانات محلية في متصفح كل مستخدم + مزامنة Supabase.

---

## ٧) بعد الإطلاق — قائمة التشغيل النهائية

1. صفحة الهبوط `landing/index.html`: ضع رابط موقعك الجديد في زر «فتح النسخة»، ورابط `ProQuote-Setup-9.6.0.exe` من GitHub Releases في زر التحميل.
2. أعد نشر صفحة Blogspot بالمحتوى المحدث.
3. (اختياري) نفس السيرفر يمكن أن يستضيف صفحة الهبوط أيضاً بدل/إلى جانب Blogspot.

---

## ملحق: خادم مزامنة خاص على نفس السيرفر (اختياري تماماً)

المعمارية الرسمية هي Supabase (مجاني وموزع). لكن إن أردت خياراً ذاتياً للشركات:
من aaPanel ثبّت **Node.js Manager** (App Store) ← أنشئ مشروعاً من `sync-server.js` بـ PM2:
```bash
API_KEY=مفتاح-سري PORT=3000 pm2 start sync-server.js --name pq-sync
```
وفي البرنامج: الرابط `http://IP:3000` والمفتاح نفسه (الشرح الكامل بعلامة «؟» في البرنامج).
